# 🌿 Gold Leaf CRM — Haaröl-Kundenverwaltung

Tablet-optimierte PWA für deine Mutter zum Eintragen von Friseur-Kunden.

## Öffnen
Doppelklick auf `index.html` → im Browser öffnen (Chrome, Edge, Firefox).

## PWA installieren (als App auf Tablet)
- **Android/Chrome**: Menü → "Zum Startbildschirm hinzufügen"
- **iPad/Safari**: Teilen → "Zum Home-Bildschirm"
- Danach wie eine native App, offline nutzbar.

## Backup
Unter ⚙️ Einstellungen → Backup (JSON) exportieren. Regelmäßig machen!

## Features
- Kunden anlegen mit Adresse, Telefon, Instagram, Fotos, Unterschrift
- Besuchs-Historie: Präsentation, Bestellung, Lieferung, Follow-up
- Schulden-Tracker + Zahlungen (Bar/Karte/Überweisung)
- Favoriten-Stern
- Suche + Filter (Besucht / Schulden / Favoriten)
- Karte (OpenStreetMap) automatisch nach Adresse
- Offline-PWA — kein Internet nötig nach erstem Laden
- Alle Daten lokal auf dem Gerät (LocalStorage)
